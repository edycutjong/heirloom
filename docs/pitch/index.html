demo instance · Lasna block times6 / 10
Press → to run the clock. Two visits; a zero-dollar spoof is struck through and does not reset the silence. Past T = 5 minutes a grace opens; one ordinary transfer cancels it and voids the pencil tally. Silence again, grace runs out, the claim is initiated (anyone may press; here the owner key pressed both steps), the claim delay runs out, and the finalize pays the heir: RELEASED. Every row is a clickable hash.

Each attack is refused and a test pins it. A spoof cannot fake life, and a sustained spray can only delay a release, never cause one; a canary outage freezes the countdown only once; only the callback proxy, relaying our reactive contract, can push a reactive state change into the vault.
